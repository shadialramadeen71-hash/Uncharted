# Max & Lily — كرتون قصير مفيد ومضحك (YouTube Shorts)

كرتون 2D Digital Animation مصنوع بالكامل بالبرمجة (Python). كل حلقة:

- **عمودية 1080×1920، 30 إطار/ث، أقل من 20 ثانية** — جاهزة لليوتيوب شورت.
- **خطّاف (Hook) في أول ثانيتين** بنص كبير متحرك + لقطات Zoom سريعة + صوت "خدش أسطوانة" عند لحظة المفاجأة.
- **حوار صوتي بالإنجليزية** (أصوات عصبية Neural لشخصيتين مختلفتين) مع **ترجمة كلمة-بكلمة** (Karaoke) ومزامنة حركة الفم مع الصوت.
- **يدين بأصابع حقيقية** (إشارة، قبضة، إبهام لأعلى، قرص الأنف، إمساك...) و**أرجل بـ IK**: القدم تثبت على الأرض أثناء المشي بدون انزلاق، مع ضربة الكعب ورفع أصابع القدم.
- **صوت مشي واقعي** مُولَّد لكل خطوة بتوقيت القدم بالضبط (كعب + انطباق مقدمة القدم + صدى غرفة)، مختلف لكل شخصية (حذاء رياضي / كعب) ويتحرك يمين/يسار مع مكان الشخصية.
- **موسيقى بدون حقوق**: الموسيقى مؤلَّفة بالكود نفسه (يوكوليلي + ماريمبا + إيقاع خفيف) فهي أصلية 100% ولن يأتيك Content ID claim. تنخفض تلقائياً أثناء الكلام (Ducking).
- **صوت بمستوى يوتيوب** (‎-14 LUFS).
- **بطاقة نصيحة** ✅/❌ في آخر الحلقة (الجزء المفيد) + "Follow" في النهاية.

وموسيقى أكورديون "musette" فالس باريسي مؤلفة بالكود. الشخصيات: الجد **Albert**، حفيدته **Mimi**، والقطة السوداء **Minou**. أصوات إنجليزية بريطانية، وخطوات على الخشب والثلج.

الشخصيات: **Albert**، **Mimi**، القطة **Minou**، الخبّازة **Madame Colette**، النادل **Gaston**، والبط.
الأماكن: الشقة، شارع باريسي، المخبز، المقهى، حديقة فيها بحيرة وبرج إيفل، ومدخل عمارة بدرج ومصعد قديم.

الستايل يتحدد في الحلقة: `Episode(..., theme="euro", mood="musette", floor="snow")`.

بجانب كل فيديو ملف `.txt` فيه العنوان والوصف والهاشتاقات للنشر.

## صنع حلقة جديدة

انسخ `episodes/ep02_burn.py` وغيّر:

1. `ep.say(...)` — الحوار (يُحوّل لصوت تلقائياً ويُحسب توقيته).
2. `choreo(ep, L)` — الحركة، مربوطة بتوقيت الجمل `L[i]["start"]` / `L[i]["end"]`:
   - `walk_to`, `hop`, `turn`, `pose(arm, hand)`, `reach("F", "nose")`, `expr("shocked")`
   - الكاميرا: `ep.punch(...)`, `ep.shake(...)` — المؤثرات: `ep.sound(t, "boing")`
   - `ep.tip = dict(...)` بطاقة النصيحة.

المحرك يرفض أي حلقة أطول من 20 ثانية.

## هيكل الكود

```
engine/audio.py      الأصوات (edge-tts)، خطوات المشي، المؤثرات، تأليف الموسيقى
engine/video.py      خط الإنتاج: صوت → حركة → مكساج → إطارات → MP4
episodes/            الحلقات + الشخصيات (Max و Lily)
```
